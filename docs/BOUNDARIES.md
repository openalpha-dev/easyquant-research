# 能力边界

本包是 EasyQuant 研究引擎的**开源客户端**：离线参考目录 + 通往托管研究 MCP 的桥接 + 可安装 Agent Skills。引擎与数据仍托管在运行时，本包不包含回测引擎、不落地行情数据、不在本地模拟计算。

## 只做历史研究

每一个运行时工具都只做历史研究：

- **不下单**、不访问资金账户、不创建或启用交易策略、不管理 API Key。
- 这条边界由运行时强制（agent API 前缀 `/api/agent/v1/**` 永不放下单/实盘/资金账户/管理接口），不是客户端的君子协定。
- AlphaSpec 工具只创建**研究草稿**并评估，`get_research_evidence` 是历史回测证据，**不是**模拟盘或实盘交易 evidence。

## 托管平台与模拟运行

本包只做历史研究，**创建策略与模拟运行（模拟盘）在托管的 EasyQuant 平台上完成**，不在本包范围内。请登录 EasyQuant 平台进行策略创建和模拟运行：

- 欢迎页（中文）：<https://trade.goeasyquant.com/welcome>
- Welcome（English）：<https://trade.goeasyquant.com/en/welcome>

平台提供可视化策略画布、AI 投研、历史回测与模拟交易：把想法写成策略、预览买卖点，草稿先预览，保存与执行由你确认。本包的研究草稿与回测结论可作为平台上策略的输入，但下单、模拟盘与实盘均由平台执行，agent API 永不暴露这些能力。

## 不给投资建议

`screen` 是按用户条件计算的筛选结果，不是推荐。回答时：

- 只陈述条件与取值，不对名单里的股票做评级、判断好坏或给买卖建议。
- 只引用工具返回的数字，原样转述 caveats，区分实际结果与推测。
- 工具不可用就停止，不换第三方数据、不在本地模拟补造结果。

## 点时口径

财务数据按公告日次日生效；股票池含区间内退市的股票；价格前复权；成交按各市场实际规则（涨跌停封板不成交、停牌不交易、整手、手续费与印花税）。数值类成本由运行时实时给出并随报告冻结，离线目录不写死。

## 额度

选股、回测、体检每人每天有次数额度；同一组参数 12 小时内重复调用不扣次。未登录体验模式额度更低、只开放部分工具。不要为凑通过结果反复提交。

## 密钥

仓库与包里**不得出现真实 API Key/密钥**。`EASYQUANT_API_KEY` 只从环境变量或 `--api-key` 读取，由用户在运行时个人中心生成。客户端不持久化、不上报密钥。
